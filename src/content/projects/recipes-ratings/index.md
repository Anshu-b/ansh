- Conducted extensive data cleaning and feature engineering for hypothesis testing & creating a linear regression model on over
230,000 recipes, including nutritional breakdown and tag preprocessing using TF-IDF, to optimize model performance.
- Implemented a Random Forest Classifier pipeline with GridSearchCV for hyperparameter tuning to categorize recipe ratings,
achieving 92% accuracy and 88% precision for classifying top-rated recipes, improving from 82% accuracy for the baseline model.
