- Built a cyber-physical smart AC system for DSC 190 (IoT & Sensors) combining an Arduino hardware controller with a Processing visualization interface.
- Used a humiture sensor, L293D motor driver, DC fan, and LCD display; applied real-time signal filtering on the Arduino and streamed structured data over serial for live visualization.
- Supported user-configurable thresholds and mode switching via the Processing interface.
