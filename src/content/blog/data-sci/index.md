## My Data Science Coursework

- ### DSC 10: Principles of Data Science
  - **Professor:** Rod Albuyeh
  - **Grade:** A
  - **Workload:** Medium/High
  - **My Course-Value Rating (out of 5):** ⭐⭐
  - **When** - Fall 2023
  - **My Thoughts:**
    - This is the first data science class you’ll ever take at UCSD, and honestly it’s a pretty solid introduction to the major - although I have some conflicting thoughts on it as mentioned below.  
    - Rod was a good teacher, but it was also kinda obvious he didn’t really want to be teaching this particular class. The fact that it was at 8 AM didn’t help my motivation to show up either.  I've heard Janine and Suraj (who is now at Michigan) really made the class enjoyable though! 
    - It’s a decently time-consuming class that focuses on statistical basics and libraries like babypandas and numpy. And honestly, why use babypandas? It’s basically just pandas with minimal changes, which only makes it trickier later when you have to unlearn babypandas quirks and actually use pandas. Midterm and Final were alright, nothing you can't solve with a few hours of good studying.
    - Overall, it’s a great intro to data science for non-majors or for DS majors who’ve never coded before since the homeworks and projects are very involved. But nearly all the material is retaught in DSC 80 in way more depth, so while it has some good projects, it’s not super critical if you already have a coding background.  
    - Would’ve been way more useful if it introduced essential tools like GitHub, or better yet, if it combined with COGS 9 to also cover the non-coding sides of data science like ethics, presentations, and sampling.

- ### DSC 20: Programming & Data Strucutres for Data Science
  - **Professor:** Marina Langlois
  - **Grade:** A
  - **Workload:** Medium/High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐
  - **When** - Winter 2024
  - **My Thoughts:**
    - Coming from mainly Java in AP Computer Science and only dabbling in Python, this class was huge for me since it really drilled in core software development concepts and got me super comfortable with Python, knowledge I still rely on today.  
    - Marina was a fantastic lecturer and awesome to talk to after class. She did a great job making the course rigorous enough that it truly mattered.  
    - The exams, homeworks, and projects were tough at first but always manageable with decent time management, which is HUGE for all data science courses.  
    - Honestly, this should be the *first* class in the major. It makes way more sense to learn Python thoroughly before jumping into specific data science libraries.
    - Funny enough, a lot of my friends think this class isn’t all that useful (even more so than I thought DSC 10 wasn’t), but I actually see it as very essential. 

- ### DSC 30: Principles of Data Science
  - **Professor:** Marina Langlois
  - **Grade:** A-
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐⭐
  - **When** - Spring 2024
  - **My Thoughts:**
    - This is probably the hardest lower-division class in the major.  
    - I used to curse out Marina while taking it because the homeworks were *so big*, most took me 8-9 hours. Writing those goddamn unit tests for each function was the bane of my existence.  
    - This class also introduces GitHub, and that first assignment was so brutal I had to call up my cracked friend Arhan at Purdue to help me debug and figure out what was going on, an experience I hated then but honestly cherish now since I use version control daily, especially at my internship.

But it all paid off, this class made prepping for interviews with LeetCode **miles** easier. Even though the class is in Java and I did most LeetCode in Python, the conceptual drilling stuck with me.

    - I’ve heard newer versions of this class with other professors are much lighter and even skip GitHub, which is honestly a shame because this course is core to actually being a data scientist or software engineer.

- ### DSC 40A: Theoretical Foundations of Data Science I
  - **Professor:** Kyle Shannon
  - **Grade:** A
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐⭐
  - **When** - Summer 2024
  - **My Thoughts:**
    - Before taking this class, it was hyped up as *the* hardest course in the lower-division DSC major, so I went in absolutely shivering my timbers (though honestly, after taking both, I think DSC 30 was worse).  
    - Kyle structured 40A in a really interesting way: all the lectures were pre-recorded and uploaded to YouTube in great quality, which I actually loved, it let me pause and keep up at my own pace, then use class time to work through practice problems (HOPS) and ask conceptual questions.  
    - This class is very different from typical coding-heavy courses; it’s super mathematical. The first half is basically calculus and linear algebra, while the second half dives into probability. Most people crush one half and struggle with the other. Probability’s always been my weak point and it was pretty obvious when I checked Gradescope and had the minimum score in the entire class on one of the homeworks. However, I still ended up doing well overall.  
      - While the class is mathematically-focused, Kyle specifically added some coding to the homeworks to tie the theory to application, which is not something all professors do for this class.
    - I found the first half especially fascinating, since it’s truly foundational for nearly every ML-related class you’ll take after (COGS 150, 118A, 118B, 185, 188; DSC 140A, 80; MATH 173A, etc.). If you're into quant finance and probability, you'll feel the same appreication for the second half. 
    - Taking it over summer in just 5 weeks with two other courses was intense and time-consuming, and the exams were genuinely tough, but Kyle makes sure students succeed through generous curves and lots of bonus opportunities.
    - **TUTOR PERSPECTIVE:** I came back as a tutor for this class in Winter and Spring 2025, which gave me even more appreciation for how well Kyle balances difficulty with student support. Seeing students struggle with the same probability concepts I did, and helping them through it, was super rewarding.
    - **SCHEDULING ADVICE**: Some people tend to take this course alognside DSC 20 or DSC 30 instead of one-at-a-time sequentially (which is what I did). My honest reccomendation is that if you are comfortable with Python, doing it with DSC 20 shouldn't be too rough. However, doing it with DSC 30 is not something I reccomend due to how heavy both classes are. Some people are "forced" to in order to meet graduation requirements and such, and if you absolutely must take 30 and 40A, surround those 2 classes with only 1-2 other courses, and make sure they're VERY light.

  - **Grade:** A
  - **Workload:** Medium
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐
  - **When** - Summer 2024
  - **My Thoughts:**

- ### DSC 80: Practice of Data Science
  - **Professor:** Sam Lau
  - **Grade:** A
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐⭐
  - **When** - Fall 2024
  - **My Thoughts:**
    - This class pretty much covers exactly what you’ll be doing in your first data science internship: tons of exploratory data analysis, basic machine learning, and most importantly, learning how to actually interpret and communicate data in words.  
    - The final project was great, it’s the first project in the DSC major that focuses on delivering a tangible product (a website deployed on GitHub) that explains and contextualizes results from your data analysis and ML models.  
    - It’s a fast-paced course that covers a lot. The first ~5 weeks are basically a repeat of DSC 10 but in real pandas instead of babypandas, then it ramps into basic machine learning models like Linear Regression and Random Forest Classifiers.  
    - I didn’t think the final was too bad, but our midterm was absurdly difficult. Sam was trying out a new online testing center format which was honestly a disaster. That said, he was great about adapting to student feedback, offering midterm redemption and switching back to paper exams for the final.  
    - The biggest factor here is time. The homeworks and projects are super hands-on and really time-consuming, but it’s all worth it for getting those essential skills down.

- ### DSC 100: Introduction to Data Management
  - **Professor:** Babak Salimi
  - **Grade:** A-
  - **Workload:** Medium
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐
  - **When** - Spring 2025
  - **My Thoughts:**
    - This class was relatively light on homework, but the exams were definitely tough and the concepts, especially relational algebra, took a solid amount of time to really get.  
    - That said, this course is absolutely critical for being a data scientist. People tend to dismiss it as just a “SQL class,” but it goes way beyond that. Even the stuff after SQL that seems pointless is actually super important.  
    - I use SQL constantly in my internship, but beyond that, knowing how to draw effective diagrams and really understand how primary and foreign keys relate tables in a relational database is huge and helped me overcome major hurdles in my intern project.  
    - A limitation is that the class mostly deals with small data sets and pretty specific database formats. I think it’d be way more impactful if it were more project-based and exposed students to common database technologies like Firebase, Supabase, and other crucial cloud storage methods. That way, it wouldn’t just cover schema design, querying, and efficient SQL, but also dive into real-world concerns like data security, pricing, and scalability for storage solutions. 
      - This is a limitation that I noticed while working on my research project with Akshay, since he assumed that I as a data scientist would know how to setup a Firebase to handle simulatenous live data streams and querying, but I really didn't know how to and had to self-learn via Youtube.

- ### DSC 106: Introduction to Data Visualization
  - **Professor:** Sam Lau
  - **Grade:** A
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐
  - **When** - Winter 2025
  - **My Thoughts:**
    - By far my least favorite class in the DSC major. By a mile.  Not "hard" by any means (especially with AI), but very time consuming and extremely annoying.
    - This class is basically all front-end development: HTML, CSS, and a *ton* of JavaScript (my least favorite language). It does cover some important design concepts for creating effective data visualizations, but skips over crucial tools and ideas like matplotlib, seaborn, or even how to pick good data in the first place.  
    - Most critically, it completely misses dashboarding with tools like Tableau, which is a universal expectation for data scientists. Honestly wild that Tableau isn’t taught anywhere in the DSC curriculum, and if any class should cover it, it’s this one.  
    - As much as I loved Sam for DSC 80, I don’t think he’s quite up to speed with DSC 106. The course feels like it’s just doing stuff with no real direction. Labs are a sequential grind through JavaScript, the projects are vaguely scoped visualizations with little actual guidance on how to build them, and lectures are mostly about design principles—like what colors to pick.  
    - The final project showcase was probably the only part of the class that felt truly well put together. It let us build a tangible product and practice telling stories with data for both technical and non-technical audiences. But even then, we were basically just encouraged to prompt-engineer our way through, without any real instruction on dashboard design or best coding practices for effective data viz.

- ### DSC 140A: Probabilistic Modeling & Machine Learning
  - **Professor:** Justin Eldridge
  - **Grade:** B+
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐
  - **When** - Winter 2025
  - **My Thoughts:**
    - This is probably the most difficult class in the major from a purely conceptual standpoint. The mathematical foundations required are very high-level, and without putting in the time and commitment, it’s pretty unlikely you’ll actually follow what’s going on.  
    - I had it with Justin, who was an excellent lecturer, his slides were super informative, and he always had a positive attitude about answering questions, no matter how basic.  
    - The labs were multiple choice on Gradescope, while the homework was a solid mix of theoretical and coding problems that did a great job breaking down the complex concepts into smaller, more digestible pieces that built on each other.  
    - Justin’s redemption policies made it a lot easier to get a good grade, but my lazy bum self didn’t bother redoing labs to claw back points, which is why I ended up with a B+, off of an A- by <1% (play stupid games, win stupid prizes 🤡).  
    - The midterms (the final was actually an optional midterm redemption) weren’t too bad and closely mirrored the labs, I hovered right around the average. Honestly, I could’ve probably pulled off an A if I applied myself more, but my Amazon interview was literally the day before the final, and I’d spent the two weeks before that doing nothing but LeetCode. I walked into the final with no studying and got about the same score as my midterms.  
    - One of the coolest parts of the class was the super homework. It really highlighted how we data scientists can get so obsessed with finding the “best” model that we completely overlook the importance of clean data processing and feature engineering. The student who won the accuracy competition didn’t have some fancy model, just a really deep understanding of the data and brilliant feature choices.

- ### DSC 140B: Representation Learning
  - **Professor:** Lily Weng
  - **Grade:** A+
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐
  - **When** - Spring 2025
  - **My Thoughts:**
    - This class is structured pretty uniquely, it's 100% homework, no exams or anything else. There was an optional extra credit project, but basically nobody did it since everyone already had high homework scores.  
    - The course covers a ton of essential high-level concepts, ranging from basic linear algebra all the way to advanced, cutting-edge explorations of LLMs. It really goes from 0 to 100 real quick.  
    - Honestly, I didn’t spend nearly as much time on this class as it deserved. If there were exams, I would’ve had to study way more, but without them, it was easy to just coast by. I fully plan to go back and revisit the LLM and later lectures to really solidify some of the stuff I’m still fuzzy on.  
    - A class like this honestly shouldn’t be this easy because the material itself is absolutely not easy. My main advice: commit yourself to learning the material even if there are no exams and start early on the homeworks, especially the later ones since the model training takes hours.

- ### DSC 190: Topics in Data Science - Advanced Algorithms
  - **Professor:** Marina Langlois
  - **Grade:** A-
  - **Workload:** High
  - **My Course-Value Rating (out of 5):** ⭐⭐⭐⭐⭐
  - **When** - Spring 2025
  - **My Thoughts:**
    - This was only the second time the course had been offered, and while it was taught by Marina, it retained the original “Justin-style” structure: 2 midterms with an optional final (which serves as a midterm redemption), plus a mix of homeworks and online labs.  
    - The material basically picks up right where DSC 30 and 40B leave off, extending into more advanced algorithms and data structures, but this time in Python.  
    - I actually found this class super useful, especially for LeetCode prep. It covered key concepts like dynamic programming and backtracking that are critical for interviews.  
    - Personally, I enjoyed and understood the first half (on advanced data structures) more than the second half (advanced algorithms), and my midterm scores reflected that.  
    - Since this is a DSC 190 elective, it’s not required, but it covers some very practical and interesting topics, so I’d recommend it if you have an open elective slot.  
    - Heads-up: it overlaps a lot with CSE 100, so if you're taking that, this class might feel repetitive.
